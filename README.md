# What is this?

Please view all pertinent information in the deployed version at: https://brinecr.github.io/

## Maintaining the career page

Edit `index.html` for content and `css/career.css` for the career page layout. The latter loads after the original template styles, preserving the existing palette without requiring the legacy Sass toolchain.

Preview from the repository directory with `python3 -m http.server 8765 --bind 127.0.0.1`, then open `http://127.0.0.1:8765/`. Check desktop and phone layouts before publishing to `master` through GitHub Pages.

Keep public wording accurate and free of confidential project, employer or customer details. Retain the current resume download and historical PDF assets when editing the page.
